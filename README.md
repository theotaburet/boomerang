# Boomerang

> Drop your photos. Get an Instagram-ready boomerang MP4. **100% in your browser.**

No upload, no server, no signup. Powered by `ffmpeg.wasm` and Web Workers.

**Try it: <https://theotaburet.github.io/boomerang/>**

## Features

- **Client-side only** — your photos never leave your device.
- **Square / Portrait / Landscape** presets optimized for Instagram, Reels, Stories, TikTok.
- **Configurable padding & background color** (default: white square padding).
- **EXIF-aware** rotation (no more sideways iPhone shots).
- **Live canvas preview** — see the loop instantly, no encode required.
- **H.264 + faststart + yuv420p** output, social-media compatible.
- **Mobile-friendly**: parallel image preprocessing in workers, single-threaded ffmpeg core (no COOP/COEP needed).

## Tech stack

- [Astro](https://astro.build) (static output, deploys anywhere)
- React 19 islands
- Tailwind CSS v4 (neo-brutalism design)
- `@ffmpeg/ffmpeg` 0.12 (WASM, in a Web Worker)
- `exifr` for orientation

## Local dev

```bash
npm install              # also auto-runs `setup:ffmpeg` (downloads ~31 MB into public/ffmpeg/)
npm run dev              # http://localhost:4321
npm run build            # static output → ./dist
npm run preview          # serve build locally
npm run setup:ffmpeg     # re-download ffmpeg-core if needed
```

The `public/ffmpeg/` folder is **gitignored** — it's regenerated by `setup:ffmpeg`.
To use a CDN instead of self-hosting, set `VITE_FFMPEG_CORE_BASE` (e.g.
`https://unpkg.com/@ffmpeg/core@0.12.10/dist/umd`) before `npm run build`.

## Tests (E2E)

```bash
npx playwright install chromium webkit   # one-time
node scripts/make-fixtures.mjs           # generate tiny test images (one-time)
npm run test:e2e                         # run all tests
npm run test:e2e:ui                      # interactive Playwright UI
```

## Deploy

Live at **<https://theotaburet.github.io/boomerang/>**: `.github/workflows/deploy.yml`
builds, runs the E2E tests and publishes `dist/` to GitHub Pages on every push to `main`.

Output is fully static, served under `base: '/boomerang'` (see `astro.config.mjs`;
set it back to `/` for a root domain). Elsewhere:
- **Netlify** — `_headers` already configured.
- **Cloudflare Pages** — caps files at 25 MiB, so build with `VITE_FFMPEG_CORE_BASE`
  pointing at a CDN instead of self-hosting the 31 MB `ffmpeg-core.wasm`.
- **Vercel / S3** — works as-is.

## Project structure

```
src/
├── lib/
│   ├── presets.ts      # Output format presets
│   ├── sequence.ts     # Pure helpers (boomerang indices, math)
│   ├── image.ts        # Decode + EXIF + pad + resize → JPEG
│   ├── encoder.ts      # ffmpeg.wasm wrapper
│   └── pipeline.ts     # Worker orchestration (single API for UI)
├── workers/
│   ├── preprocess.worker.ts
│   └── encode.worker.ts
├── components/         # App, Dropzone, Settings, Preview, ProgressBar, ExportButton
├── pages/index.astro
└── styles/global.css   # Neo-brutalism design tokens
```
